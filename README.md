# 🎮 Análisis de ventas de videojuegos - EDA y Dashboard en Excel

## 📖 Descripción del proyecto

Este proyecto consiste en un análisis exploratorio de datos (EDA) sobre un conjunto de datos de ventas de videojuegos, utilizando Excel como herramienta principal para la limpieza, análisis y visualización.

El objetivo del proyecto es identificar patrones y tendencias relevantes en las ventas globales de videojuegos, analizando aspectos como:

- evolución de las ventas a lo largo del tiempo
- plataformas con mayores ventas
- géneros más vendidos
- distribuidoras con mayor peso en el mercado
- juego más vendido del dataset

Además del análisis, se ha desarrollado un dashboard visual en Excel para presentar los principales indicadores de forma clara y profesional.

---

## 🎯 Objetivos

Los objetivos principales de este proyecto son:

- limpiar y preparar los datos originales
- realizar un análisis exploratorio de ventas
- detectar las variables más relevantes del dataset
- resumir los hallazgos principales mediante gráficos y tarjetas KPI
- construir un dashboard final en Excel con un diseño visual cuidado
